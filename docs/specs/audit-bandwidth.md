# 审计实时带宽

## 目标和范围

在日志审计页面新增上传/下载带宽曲线，用于观察客户端是否持续占用带宽。取已提交的 client_inbounds 原始累计字节计数，不使用计费倍率后的 client_traffics、不以连接关闭时的访问日志推算实时速率。复用既有本地/子节点流量同步完成点，每节点至多每4秒批量读取一次计数，无新增节点 RPC、无逐客户端查表。

## 采样和持久化

相邻成功采样按实际经过秒数计算字节/秒。首次出现的关联只建立基线，计数回退、关联变更和超过30秒采样中断重新建立基线，不把重启/清零/断线补发误画成峰值。速率是面板观察到的约5秒平均值，节点同步延迟仍影响观察时刻。每节点的成功连续覆盖独立记录，空闲为0、缺失为未知。

实时值保存在有界内存最新样本中；浏览器每5秒读取，累计最多720点（约1小时），切换客户端/节点重建实时曲线。分钟字节及覆盖时间独立压缩保存24小时，每30秒批量刷入。每次进程启动使用独立 epoch，分钟记录按绝对值幂等覆盖，避免失败重试重复累加，重启不覆盖先前进程已保存的分钟数据。未刷盘的最多30秒数据可能在进程崩溃时丢失。

## 界面和接口

GET /panel/api/audit/bandwidth：当前上传/下载速率、采样时间和数据新鲜度。
GET /panel/api/audit/bandwidth/history：24小时完整分钟桶的平均上传/下载速率及覆盖时间。

管理员权限，沿用 nodeId（0全部、-1本机、正数子节点）与 client 筛选。带宽无法按网站归因，网站与访问日期筛选不影响此卡片，界面明确说明。提供实时/24小时切换、上传/下载当前值、采样缺失提示；分钟无覆盖不填成0，不伪造既有历史。

新增 AuditBandwidthMinute 同时注册 allModels 与 migrationModels；完整审计 ZIP 同时包含此表。清空审计日志时同步清除此表和内存历史，绝对清理水位阻止旧缓存刷回；一般保留规则不改变固定24小时窗口。

## 验收

未关闭的长连接仍产生速率；倍率不放大带宽；重复采样不重复计量；重置/重启/关联变化/采样断线无虚假峰值；客户端和节点隔离；持续覆盖的空闲显示0，缺失为未知；分钟数据幂等刷盘与跨 epoch 合并；清理后不复活；查询仅访问紧凑分钟表和内存样本。

## 默认一小时实时窗口

实时横轴固定显示当前时间前1小时至当前时间，继续每5秒刷新。打开页面立即请求既有24小时分钟历史，取最近1小时作为历史底图，再拼接当前会话5秒采样；重叠区优先实时采样。滚动裁剪过期样本，网络/采样缺失保留断点，历史空白不补0。24小时模式保持分钟均值。文案区分时间范围与刷新频率。

## 刷新一致性（2026-10-18）

最近一小时实时图统一读取后端保存的细粒度采样，不再以分钟均值补回历史。采集独立于页面访问；每节点最多保存最近一小时约 900 次采样，仅保留非零客户端速率以及节点覆盖时间，查询按五秒桶聚合节点、客户端筛选，缺失采样显示断点。刷新页面保留已采集峰值；面板进程重启或清理审计后细粒度缓存重新开始，不能从分钟均值恢复峰值。24 小时分钟均值继续持久化，不混入实时曲线。
