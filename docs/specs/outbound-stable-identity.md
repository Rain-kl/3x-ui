# 出站固定标识与显示名称

核心路由使用 outboundTag，不能使用会变的备注。以 tag 作为固定 ID，面板属性 panelId 与 tag 一致；remark 为显示名称。已有出站沿用当前 tag，不重写路由、均衡器选择器、观测器或拨号代理引用。新建出站生成 ob-UUID，备注改名、编辑凭据和重新导入连接均保留 ID。JSON 编辑若试图修改已存在出站 ID 则明确拒绝。导入/复制为新出站时生成新 ID。

模板保存和主子出站同步保留 panelId、remark，核心运行配置剥离这两个面板字段。已有订阅出站沿用身份映射的固定 tag，供应商备注变化只更新 remark，不改稳定 tag。已有缺省系统 tag（direct/blocked/api 等）不重命名。

路由与均衡器选择使用固定 ID，选项展示名称与 ID。显示名称重复不影响引用唯一性。删除为独立明确操作；改名不删除或重建路由。验收包括新建、改名、重新导入、旧配置兼容、主子同步及真实核心目标引用保持不变。
