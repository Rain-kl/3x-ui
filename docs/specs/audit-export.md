# 审计数据导出

## 产品规则

管理员可在日志审计页面导出 ZIP：全部网站流量、指定客户端的网站流量、日志库全部数据。前两种覆盖当前保留周期的所有日期和节点，网站聚合同时合并详细记录与归档汇总，不重复计量。客户端导出必须明确输入客户端标识。全库导出涵盖审计详细记录、每日汇总、分钟统计、去重收据和带宽分钟历史，不导出账号、订阅凭据或其他面板业务表。

## 数据与接口

GET /panel/api/audit/export?kind=sites|client|database&client=...

仅管理员身份可用；子节点日志已集中到主节点时拒绝本地导出。返回 application/zip，网站数据采用 UTF-8 CSV（字节单位），原始表采用逐行 JSON。manifest.json 记录 UTC 导出时间、范围、字段和保留策略。以数据库一致性只读快照遍历，不逐条关联查询、不全量加载内存；同一面板最多一个导出，5 分钟超时并响应取消。先生成临时归档再发送，失败不会发送半个 ZIP；成功或失败均删除临时文件。

## 验收

详细记录和归档记录各出现一次；指定用户不包含其他用户；全库包含五张审计表；无数据时仍产生有效空归档；非法类型、缺少客户端和集中式子节点明确报错；CSV 文本防止电子表格公式执行；下载取消释放连接及文件。
