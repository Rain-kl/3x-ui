# 用户用量及续费提醒

/usage 显示客户端独立流量周期的下一次重置日期，按面板时区计算；小时、每天、每周日和每月指定日期与现有定时任务一致，月底不足指定日取最后一天；未配置显示不自动重置。

用户 Bot 启用时每分钟扫描已绑定且启用的客户端。剩余有效期向上取整为 7、3、1 天时发送续费提醒，每个绑定、到期时间和档位只入队一次，数据库事务保存去重状态和待发消息。重启继续投递，续期后按新到期时间重新提醒。停机跨过的旧档位不补发，恢复后只提醒当前档位。无限期、未开始计时、过期和禁用客户端不提醒。发送前核验绑定与到期时间，避免解绑和续期后的过时提醒。

登录会话默认值从 360 分钟调整为 4320 分钟（72 小时），保留管理员显式设置；已有会话重新登录后使用新的默认值。
