# 主节点路由规则同步

每条本机路由规则增加面板属性 sync（默认关闭），仅主节点本机视图可设置。保存主节点 Xray 配置时，以主节点全部标记 sync 的规则及其顺序生成权威快照，并立即向全部启用子节点下发。api、均衡器内部控制规则禁止开启同步。sync、panelSyncSource 等面板属性不进入核心运行配置。

子节点把同步规则作为独立只读组，放在 api 控制规则之后、本地规则之前；保留本地规则及 routing 的其他设置。子节点或主节点远程编辑该节点本地规则不会修改同步组。关闭同步、删除源规则时用新快照撤回相应副本；空快照撤回全部副本。禁用规则保留禁用状态。没有启用过同步的主节点不向子节点发送空快照。

使用现有 Setting 表保存主节点快照和递增版本，与模板在同一事务提交。节点专用 POST /panel/api/server/routing/sync 接收 source（主节点稳定 GUID）、revision、rules；校验权限与数据格式，拒绝更换来源和相同版本不同内容，旧版本不覆盖新版本。同版本应用失败可重试。模板与接收版本同事务保存，运行态应用成功后单独记录已应用版本，进程异常或失败不会被提前标记成功。

节点校验同步规则引用的出站、均衡器和入站标签；缺失时返回明确错误，保留旧快照，不剥离匹配条件、不回退到默认出站、不跨节点猜测标签。同步规则及全部均衡器配置，不复制节点入站或代理出站定义。子节点配置路由脚本时拒绝安装非空同步组，避免核心忽略规则却报告成功；有同步组的子节点同样不能启用路由脚本。规则中的地理数据库引用仍要求各节点安装对应文件，核心应用失败会明确回传。

运行中的子节点通过现有 RestartXray(false) 协调立即生效，优先热更新，失败按既有策略回退重启。停止的核心保持停止，保存供下次启动。旧构建不支持该 RPC 时报告接口错误，需升级；不得回退到覆盖全部规则的旧接口。主节点返回具体失败节点，保留已保存期望状态；后台每 30 秒有界并发重试，包括离线恢复和新增节点。已应用版本不重复保存/重启。子节点接收不再向下广播，存在启用下游节点的面板拒绝接收，避免主节点相互覆盖。

验收：两子节点保留不同本地规则，收到同一开启同步的规则及顺序；重复保存不增生副本；源规则改动、禁用、关闭同步及删除正确收敛；空快照撤回；离线恢复与新增节点补发；乱序和相同版本篡改被拒绝；引用缺失不会扩大匹配范围；应用失败向主节点报告且再次请求能重试；真实运行核心立即 TestRoute 改变且无需人工重启；面板字段不出现在核心配置中。

## 本地前置规则

新增面板属性 localPre（默认 false），与 sync 互斥，仅本地非受管规则可设置，子节点远程视图同样可设置。执行顺序固定为 API → 本地前置 → 主节点同步组 → 普通本地；各组内保留顺序。本地前置规则仍支持禁用和编辑，不向其他节点广播。同步刷新、撤回和普通保存必须保留前置组，主节点快照不得设置 localPre；运行配置剥离该面板字段。前端在编辑时和列表中明确展示类型，并禁止拖动穿过其他组造成错误优先级。

来源 IP 拒绝规则放入本地前置区，即使目标命中主节点 direct 分流也必须先被拒绝。本功能作用于代理请求转发，不改变 TCP 监听及 HTTP CONNECT 的初始应答时机。

## 主节点均衡器同步

主节点保存 Xray 配置时，无需勾选路由规则同步，也下发全部 routing.balancers、observatory、burstObservatory。balancing 是可选的权威配置块，包含显式 balancers 数组；旧规则快照未携带该块时保留子节点均衡配置。版本与哈希同时覆盖规则和均衡配置，单独新增、修改、排序、删除均衡器或调整探测参数也必须递增版本。最后一个均衡器删除后发送空数组，并移除受管观测器和内部回环配置。未配置过均衡器或共享规则时不发送空快照。

主节点为均衡器和观测器的唯一配置来源，子节点收到后替换对应配置；普通子节点模板保存不能覆盖它们。保留子节点入站、普通本地路由、系统出站和其他模板设置。均衡器间备用链所需的 _bl_ 回环出站及内部规则随配置重建，不能被通用本地规则截获。引用的普通出站由既有出站同步机制维护；接收端在合并后的配置中验证选择器、备用出站和规则引用，缺失时明确返回具体标签，保留原模板及回执，后台可在出站到齐后重试。不得因配置缺失静默改为直连。

全部启用子节点保存后立即接收，离线和新增节点沿用每 30 秒重试；运行中的核心经现有协调入口立即应用，观测器变更按核心能力自动重启，无需人工重启；停止核心保持停止。旧子节点不理解 balancing 时不得将快照标记为成功，须明确报告升级要求。

验收：无共享规则时新增均衡器仍产生快照；重复保存不增版本；策略、选择器、备用链、观测器变更和最终删除正确收敛；真实运行核心可以通过同步的均衡器选择出站；子节点保存保护、旧快照兼容、引用失败无副作用、离线恢复与新增节点补发。
