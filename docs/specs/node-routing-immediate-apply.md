# 子节点远程路由保存即时生效

主节点保存选中子节点的路由规则，通过现有 POST /panel/api/server/routing 下发；子节点本地保存与远程保存必须使用同一核心配置协调路径。配置保存后，若 Xray 正在运行，调用 RestartXray(false)：优先通过 RoutingService 热更新，只有核心不支持的配置变化或热更新失败才进入已有重启回退。已手动停止的核心继续保持停止，规则仍可保存供下次启动使用。

规则内容相同也必须检查运行时是否已与持久化配置对齐，允许重复保存重试曾失败的应用；不能以模板规则未变化代替运行时已生效。持久化失败或配置协调失败须在响应中返回 success=false，包含具体阶段和原始原因；主节点须收到该错误，不能显示保存成功。协调失败时保留已保存的期望配置，供修正或再次保存重试，不谎称运行配置已更新。

维护范围：子节点路由控制器、XraySettingService/XrayService 的现有保存与协调方法、主节点 Remote.PushRoutingRules 的错误传播。保持节点级入站标签去前缀、控制入站优先规则、禁用规则过滤和节点鉴权规则。

验收：实际运行的子节点核心收到主节点保存后，TestRoute 对相同目标立即返回新出站，热更新时核心实例不被替换；重复保存也对齐运行态；协调失败在子节点和主节点响应中明确可见；停止的核心保存后不被拉起。
