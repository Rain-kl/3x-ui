# 用户 Bot 自定义指令

## 实现

独立 TelegramCustomCommand 表以规范化指令名作为主键。管理员 API 读取有序列表、校验并事务替换整个集合；事务内记录更新日志。使用独立表避免 Bot 设置整体保存时覆盖指令，也不占用通用面板设置键。新增模型同步注册 allModels 与 migrationModels。

Bot 只在内置 switch 的 default 分支查询启用项，静态回复走既有 reply，保留输入、输出、失败日志及移除旧键盘行为；匿名聊天开关不影响指令响应，黑名单仍生效。回复不执行脚本、模板、HTML 或 Markdown。

原生菜单每轮 getUpdates 前读取配置，只在名称/说明/启用状态变化时调用 setMyCommands；成功后更新接收器内的菜单快照，失败重试且不终止轮询。仅修改回复不请求 Telegram 菜单更新。启用项加7个内置项最多100项。无额外收件线程、无需重启 Bot；菜单刷新通常受25秒长轮询和 Telegram 客户端缓存影响。

前端新增独立 Tab，使用生成的 Zod 合约、React Hook Form 和既有管理员 API 提供新增/编辑/删除/启停。当前集合保存成功后更新 Query 缓存；失败显示具体错误并保留编辑内容。列表以20项分页，启停按指令主键定位，避免第二页行索引导致误改。
