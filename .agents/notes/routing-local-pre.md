# 本地前置规则

用户的子节点 sourceIP=geoip:cn 拒绝规则位于共享 direct 分流之后，按首个命中执行时会被目标域名放行。既有同步组只读且总在本地组之前，拖动无法解决。

新增 localPre 面板字段，所有模板替换和保存统一分组为 API、本地前置、主控组、本地普通；组内稳定。共享快照拒绝携带 true，安装时剥离该字段。保存子节点本地规则仍保留旧共享组，最终重排保护优先级；运行态剥离面板属性。

前端表单将同步与前置互斥；客户端编辑后重排，跨组移动被阻止；远程保存成功后重拉真实规则。此功能阻断后续转发，不表示监听端口不能完成 TCP/HTTP CONNECT 初始应答。

已验证共享快照连续替换后仍保留 API → 本地前置 → 共享 → 普通本地顺序，并在真实核心上验证来源网段拒绝优先于后置 direct。HTTP CONNECT 仍可能返回初始 200，但后续请求数据不能抵达目标。
