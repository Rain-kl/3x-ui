# 配套核心依赖的离线校验和

核心源码目录中的测试会留下 Git 忽略的证书和地理资源文件。按工作目录生成模块 ZIP 会包含这些额外文件，从而得到与远程 Git 提交模块不同的 h1；即使本地构建正常，远程 CI 下载后也会报 checksum mismatch。

在发布前使用 git archive 导出 c662a740ba39 的纯提交树，再由 golang.org/x/mod/zip 生成标准模块 ZIP。比对确认已跟踪文件内容完全相同，差异仅为本地测试产物。更新面板 go.sum，替换本次临时生成的依赖缓存，并以 go mod verify 通过为收尾。

只修正新依赖版本的模块内容校验和；模块版本与 go.mod 校验和不变。配套核心提交及 feat.4 二进制仍须先发布，再发布面板。
