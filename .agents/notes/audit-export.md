# 审计 ZIP 导出

使用一致性只读快照复用网站指标查询，合并互斥的详细记录与每日汇总。每次只游标读取一行，压缩到权限受限的临时文件；成功后再使用浏览器原生下载，避免后端和浏览器 JavaScript 全量缓存。全库以 JSONL 保留五张审计表的数据库列（包含内部交付/去重字段），不包含其他业务表。

导出限制一个并发，生成超时 5 分钟，取消传播到数据库。独立延长此下载的 HTTP 写入期限，不改变其余接口的 30 秒超时；生成和传输失败均释放文件。CSV 对公式起始字符转义，包含 BOM，数字单位为字节。

检查覆盖详细/归档合并、客户端隔离、原始表齐全、ZIP HTTP 响应和字段格式。仓库无新导入能力；该 ZIP 是审计数据档案，不是面板整库备份。
